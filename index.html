Visa analytics chatbot

A RAG chatbot on AWS Bedrock and Claude Haiku 4.5 that answers visa questions for a global staffing team. The model never writes a link itself. It cites short IDs like [1]. When the answer is done, an ID-mapping step swaps each ID for the source URL stored in that chunk's metadata. So it cannot make a link up.

Lead ML Engineer · In production · AWS Bedrock, Claude Haiku 4.5, RAG, Python, FastAPI

    GoLend AI assistant

    Loan officers ask questions in plain English and get the answer in plain English. Amazon Nova Pro writes a read-only SQL query, runs it, and explains the result. To find the right tables it mixes BM25 with pgvector search (IVFFlat and HNSW indexes) and MMR re-ranking, with AWS Guardrails on top.

    Lender IQ (GraphRAG)

    Plain vector search struggles with questions like "which guarantors co-sign loans in three or more portfolios?" because the answer is spread over many files. We used LLMs to pull entities and relationships out of 10,000+ financial documents into Neo4j, then answered by walking the graph. Accuracy went up 40%.

    ML Engineer at Fusemachines · 40% accuracy lift · Neo4j, GraphRAG, LangChain, FastAPI, GPT

    lender-iq / graphrag.querydone · 1 match · 6 edges

    QWhich guarantors co-sign loans across 3+ portfolios?

    MATCH (g:Guarantor)-[:CO_SIGNS]→(:Loan)-[:IN]→(p:Portfolio) WITH g, count(DISTINCT p) AS n WHERE n ≥ 3

    A applicant · G guarantor · L loan · P portfolio

    G-17 is the only guarantor who co-signs loans in three or more portfolios. Its loans L-204, L-118 and L-152 are in P-retail, P-sme and P-agri.

    cc-explain-this ↗

    Claude Code moves fast, and some of its shell commands are hard to read at a glance. This open-source plugin adds a side pane that explains each step in one plain sentence. It flags risky steps (deletes, pushes, installs) and says why a step failed. The explanation is written after the step is done, so Claude does not slow down.

    Open source, MIT · TypeScript, Claude Code plugin, Claude Haiku

    claude code · ~/auth-service5 steps · 1 failed · 1 risky

    > Make sessions last 30 minutes.
    ⏺Bash(grep -rl "SESSION_TTL" src)⎿ src/auth/session.ts
    ⏺Update(src/auth/session.ts)- TTL = 15 * 60+ TTL = 30 * 60
    ⏺Bash(npm test)⎿ 2 failed, 41 passed
    ⏺Update(test/session.test.ts)⎿ updated 2 lines
    ⏺Bash(git push origin main)⎿ main → main

    explain thisplugin

    1. ●Bash

      Searches the code for every file that sets the session timeout.

    2. ●Edit

      Changes the session timeout from 15 to 30 minutes.

    3. ●Bashfailed

      Two tests fail because the test clock still expects 15 minutes.

    4. ●Edit

      Updates the two tests to expect the new 30-minute timeout.

    5. ●Bashrisky

      Sends your commits to the shared main branch, where others will see them.

    jev-router ↗

    A small open-source Rust proxy that picks the model and effort level for each message you send to Claude Code. Quick questions go to Haiku, everyday work to Sonnet, and hard or risky work to Opus. It also watches the prompt cache, so it does not switch models mid-conversation when that would cost more than it saves.

    Open source · Rust, LLM routing, prompt caching, Claude Code
