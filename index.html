cc-explain-this ↗

Claude Code moves fast, and some of its shell commands are hard to read at a glance. This plugin adds a side pane that explains each step in one plain sentence. It flags risky steps (deletes, pushes, installs) and says why a step failed. The explanation is written after the step is done, so Claude doesn't slow down.

jev-router ↗

A small Rust proxy that picks the model and effort level for each message you send to Claude Code. Quick questions go to Haiku, everyday work to Sonnet, and hard or risky work to Opus. It also watches the prompt cache, so it won't switch models mid-conversation when that would cost more than it saves.
